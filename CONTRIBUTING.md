# 🤝 Como Contribuir com o IA para Todos

Obrigado por querer fazer parte desta iniciativa! Toda contribuição — de professores, pesquisadores, desenvolvedores, pais ou estudantes — é bem-vinda e valorizada.

---

## 🌟 Formas de Contribuir

### 1. Compartilhar sua Experiência de Sala de Aula

Se você é professor(a) e usou alguma atividade deste repositório, sua experiência é um presente para toda a comunidade.

**Como fazer:**
- Acesse a aba **Discussions** neste repositório
- Abra uma nova discussão na categoria "Experiências de Sala"
- Conte: o que funcionou, o que não funcionou, como sua turma reagiu, o que você adaptou

Não precisa ser um relato perfeito. Uma anotação simples já ajuda muito!

---

### 2. Propor uma Nova Atividade

Tem uma ideia de atividade sobre IA que ainda não está aqui? Adoraríamos incluir!

**Como fazer:**
1. Abra uma [Issue](../../issues/new?template=nova-atividade.md) com o template "Nova Atividade"
2. Preencha os campos: ano, tema, resumo, objetivos
3. Nossa equipe vai revisar e entrar em contato
4. Se aprovada, você pode enviar o conteúdo completo via Pull Request (ou nós ajudamos você a formatar)

**O que procuramos em novas atividades:**
- ✅ Relevante para a realidade de escolas públicas brasileiras
- ✅ Funciona offline ou com recursos mínimos
- ✅ Inclui momento de reflexão ética
- ✅ Linguagem adequada para a faixa etária
- ✅ Alinhada à BNCC

---

### 3. Corrigir Erros ou Atualizar Conteúdo

Encontrou um erro, informação desatualizada ou link quebrado? 

**Como fazer:**
- Abra uma [Issue](../../issues/new?template=correcao.md) com o template "Correção"
- Descreva o problema e onde ele está
- Se souber a correção, pode propor via Pull Request

---

### 4. Adaptar para Sua Realidade Regional

O Brasil é imenso e diverso. Uma atividade pensada para o sul pode precisar de adaptações para o nordeste, para regiões rurais, para comunidades quilombolas ou indígenas.

**Se você fez adaptações:**
- Compartilhe nas Discussions
- Ou abra um PR com a versão adaptada em uma subpasta `adaptacoes/`

---

### 5. Traduzir o Conteúdo

Queremos que este material chegue ainda mais longe:
- **Espanhol** — para uso em países vizinhos e comunidades de fronteira
- **Inglês** — para compartilhamento internacional
- **Línguas indígenas** — para comunidades indígenas do Brasil

Se você tem fluência em alguma língua e quer ajudar com tradução, abra uma Issue na categoria "Tradução".

---

### 6. Contribuir com Código

Se você é desenvolvedor(a) e quer contribuir com:
- Scripts para gerar PDFs das atividades automaticamente
- Ferramentas de navegação offline do conteúdo
- Scripts de validação de conteúdo (links, formatação)
- Integrações com o pendrive Multicortex

Veja as Issues com a tag `código` e abra um PR!

---

## 📋 Como Fazer um Pull Request

Se você nunca fez um PR no GitHub, não se preocupe — é mais simples do que parece:

1. Clique em **"Fork"** no canto superior direito deste repositório
2. No seu fork, faça as alterações ou adicione o arquivo
3. Clique em **"Contribute" → "Open Pull Request"**
4. Preencha a descrição explicando o que você fez
5. Aguarde a revisão da nossa equipe (costumamos responder em até 7 dias úteis)

---

## 📏 Padrões de Qualidade

### Estrutura de arquivos
```
nome-da-atividade/
├── descricao.md           ← Resumo de 5 linhas (obrigatório)
├── para-o-professor.md    ← Roteiro completo (obrigatório)
├── folha-do-aluno.md      ← Material do estudante (obrigatório)
└── recursos/              ← Imagens e materiais extras (opcional)
```

### Cabeçalho obrigatório em todo `para-o-professor.md`
```markdown
**Ano:** X º ano | **Duração:** XX min | **Recursos:** ... | **Offline:** ✅/⚠️/❌
```

### A Caixa de Ética é obrigatória
Toda atividade deve ter um momento de reflexão ética no final. Sem isso, o PR não será aceito.

### Linguagem
- Português brasileiro claro e acessível
- Evite jargões técnicos sem explicação
- Termos em inglês devem ser explicados na primeira vez que aparecem

## 🤗 Código de Conduta

Este projeto adere ao [Código de Conduta do Contributor Covenant](CODE_OF_CONDUCT.md).

Em resumo:
- Seja respeitoso(a) com todos os colaboradores
- Valorize perspectivas diferentes das suas
- Foco no que é melhor para as crianças e professores das escolas públicas
- Reporte comportamentos inadequados via Issue ou email
