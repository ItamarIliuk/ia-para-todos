# 📷 3º Ano — "Como a IA Vê o Mundo?"

**Faixa etária:** 8-9 anos | **Ciclo:** Anos Iniciais

---

## 💡 Visão Geral do Ano

No 3º ano, o tema central é **visão computacional** — a capacidade da IA de "ver" e interpretar imagens. É um tema concreto, visual e fascinante para crianças desta faixa etária.

Por que visão? Porque é a área de IA mais presente no cotidiano das crianças: o rosto reconhecido pelo celular, o filtro do Instagram que coloca orelhinhas de gato, o Google Fotos que organiza as fotos por pessoa — tudo é visão computacional.

---

## 🎯 Objetivos de Aprendizagem

- [ ] Compreender que computadores "veem" de forma diferente dos humanos (pixels, números)
- [ ] Experimentar ferramentas de classificação de imagens (Teachable Machine)
- [ ] Identificar aplicações de visão computacional no cotidiano
- [ ] Discutir os riscos do reconhecimento facial para crianças
- [ ] Perceber que a IA pode "ver" melhor em algumas tarefas mas pior em outras

## 👩‍🏫 Orientações para o Professor

### O conceito central: pixels e números

Para um computador, uma imagem é uma grade de números. Cada número representa a cor de um ponto (pixel). Quando a IA "vê" uma foto, ela na verdade lê uma tabela enorme de números.

**Analogia poderosa:** Um mosaico de banheiro, visto de perto, são só quadradinhos coloridos. Visto de longe, forma uma imagem. A IA faz o oposto — ela analisa cada quadradinho (pixel) para entender a imagem toda.

### Ferramenta principal: Teachable Machine (Google)

- Site: `teachablemachine.withgoogle.com`
- Funciona no navegador, sem instalação
- Permite treinar uma IA para reconhecer imagens/sons usando a webcam
- Dados ficam no computador local — ótimo para privacidade!
- **Não exige conta ou login**

### ⚠️ Atenção especial neste ano

A atividade 03 (reconhecimento facial) exige cuidado particular com privacidade. **Nunca** use fotos reais de alunos em ferramentas de IA. Use sempre imagens genéricas ou ilustrações.
