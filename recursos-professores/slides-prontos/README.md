## Como Obter os Slides

Os slides das formações e de algumas atividades estão disponíveis como:

1. **Apresentações Google Slides** (abertas e editáveis):
   - Acesse pelo repositório GitHub e clique no link correspondente
   - Faça uma cópia para o seu Google Drive antes de editar

2. **Versão PowerPoint (.pptx)**:
   - Disponível para download na seção Releases do repositório
   - Compatível com LibreOffice Impress (gratuito e offline)

3. **Versão PDF** (leitura apenas):
   - Menor tamanho de arquivo
   - Ideal para imprimir ou compartilhar por WhatsApp

## Criando Seus Próprios Slides

Se você quiser adaptar ou criar slides próprios, seguem as diretrizes visuais do projeto:

**Paleta de cores:**
- Azul principal: `#2563EB`
- Verde ação: `#16A34A`
- Laranja ética: `#EA580C`
- Fundo claro: `#F8FAFC`
- Texto: `#1E293B`

**Tipografia:**
- Títulos: Inter ou Montserrat Bold
- Corpo: Inter ou Open Sans Regular
- Código: JetBrains Mono (quando necessário)

**Princípios visuais:**
- Máximo de 4 elementos por slide
- Imagens ilustrativas (não de pessoas reais sem permissão)
- Ícones simples e universais
- Contraste suficiente para acessibilidade

## Contribuindo com Slides

Se você criar slides adaptados para sua realidade escolar e quiser compartilhar com a comunidade:

1. Abra uma Discussion no repositório com a tag "slides"
2. Descreva para qual turma/contexto foram criados
3. Compartilhe o link do Google Slides ou faça upload do arquivo

A comunidade agradece! Materiais adaptados para diferentes regiões e contextos são extremamente valiosos.
