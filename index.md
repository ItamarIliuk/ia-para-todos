# 🤖 IA para Todos

**Currículo completo de Letramento em Inteligência Artificial para o Ensino Fundamental (1º ao 9º ano) de escolas públicas brasileiras.**

Desenvolvido pelo **LABRIOT — Laboratório de Robótica e IoT** da UTFPR Campus Ponta Grossa, em parceria com o projeto **Multicortex**.

Coordenação: **Profa. Dra. Itamar Iliuk**

---

## ✨ Por que este projeto existe?

O letramento em IA não pode ser privilégio de escolas privadas ou alunos de famílias com mais recursos. Este projeto é **gratuito, offline-first e alinhado à BNCC** — pensado para a realidade das escolas públicas brasileiras.

## 📦 Como Usar

```
1. Baixe ou clone o repositório
2. Cada atividade tem:
   - para-o-professor.md  → roteiro completo de 50 minutos
   - folha-do-aluno.md   → para imprimir e distribuir
3. Funciona 100% offline — sem internet necessária
```
