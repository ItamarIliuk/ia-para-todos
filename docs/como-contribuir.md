# 🤝 Como Contribuir com o IA para Todos

Bem-vinda(o)! Este projeto vive e cresce com a contribuição de educadores, pesquisadores e entusiastas de educação. Toda ajuda é bem-vinda — desde uma correção de digitação até uma atividade completa nova.

---

## Formas de Contribuir

### 🟢 Para qualquer pessoa (sem precisar saber GitHub)

**1. Reporte um problema ou dê sugestão:**
- Vá em [Issues](https://github.com/ItamarIliuk/ia-para-todos/issues)
- Clique em "New Issue"
- Escolha o template mais adequado
- Descreva com detalhes

**2. Participe das Discussões:**
- Vá em [Discussions](https://github.com/ItamarIliuk/ia-para-todos/discussions)
- Compartilhe sua experiência usando o material
- Faça perguntas ou dê sugestões
- Conecte-se com outros educadores

### 🟡 Para quem tem conta no GitHub

**3. Proponha uma nova atividade:**
Abra uma Issue com o template "Nova Atividade" preenchido. Inclua:
- Ano e tema
- Objetivos pedagógicos
- Recursos necessários
- Rascunho do roteiro

**4. Corrija ou melhore conteúdo existente:**
- Fork o repositório
- Faça suas alterações na sua cópia
- Abra um Pull Request descrevendo o que mudou e por quê

### 🔵 Para professores que já aplicaram o material

**5. Compartilhe relatos de sala de aula:**
Crie uma Discussion na categoria "Relatos de Sala" descrevendo:
- Qual atividade aplicou
- Ano e contexto da escola (cidade, infraestrutura)
- O que funcionou bem
- O que precisaria ser ajustado
- Reação dos alunos

Esses relatos são incrivelmente valiosos para melhorar o material!

## Padrões de Qualidade

Para manter a consistência do projeto, toda contribuição deve:

### Atividades novas

```
✅ Ter roteiro para o professor (para-o-professor.md)
✅ Ter folha do aluno (folha-do-aluno.md) quando relevante
✅ Incluir a "Caixa de Ética" (5-10 min ao final)
✅ Ter versão offline OU indicar claramente o recurso necessário
✅ Estar alinhada à BNCC (mencionar ao menos 1 competência)
✅ Usar linguagem adequada à faixa etária
✅ Incluir a licença no rodapé
✅ Mencionar o LABRIOT/UTFPR na autoria
```

### Estrutura de arquivos

Novas atividades seguem este padrão:
```
anos-iniciais/
  [N]-ano/
    atividades/
      ativ-[NN]-[nome-descritivo]/
        para-o-professor.md   ← obrigatório
        folha-do-aluno.md     ← quando aplicável
        recursos/             ← imagens, materiais impressos
```

### Tom e linguagem

- Linguagem inclusiva (sem binarismo de gênero quando possível)
- Exemplos do contexto brasileiro (não traduções de exemplos americanos)
- Sem jargão técnico desnecessário
- Acolhedor para professores sem formação em tecnologia
- Sem alarmismo excessivo sobre IA, mas sem ingenuidade também

## Processo de Revisão

Toda contribuição passa por revisão antes de ser incorporada:

1. **Abertura do PR** — você descreve o que está propondo
2. **Revisão pedagógica** — verificação de alinhamento BNCC e adequação à faixa etária
3. **Revisão técnica** — verificação de precisão das informações sobre IA
4. **Revisão ética** — verificação dos princípios do projeto
5. **Merge** — incorporação ao repositório principal

O prazo típico de revisão é de **2 semanas**. Para contribuições urgentes ou de alto impacto, entre em contato diretamente pelas Discussions.

## Reconhecimento de Contribuidores

Todas as contribuições são reconhecidas:

- **Contribuidoras e contribuidores** são listados no README principal
- **Atividades contribuídas** têm autoria creditada no arquivo
- **Relatos de sala de aula** podem ser anonimizados se desejado
- **Pesquisas usando o material** são linkadas na seção Publicações

## Código de Conduta

Este projeto adota o [Código de Conduta do Contributor Covenant](CODE_OF_CONDUCT.md). Em resumo:

- Seja respeitoso(a) e construtivo(a)
- Foco no conteúdo, não nas pessoas
- Diversidade de perspectivas é bem-vinda
- Comportamento abusivo resulta em banimento
