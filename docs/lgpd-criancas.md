# 🛡️ LGPD e Proteção de Dados de Crianças — IA para Todos

> *Lei Geral de Proteção de Dados (Lei nº 13.709/2018) — O que todo professor e pai precisa saber*

---

## Por que isso é importante?

Quando crianças usam ferramentas digitais — incluindo ferramentas de IA — elas geram dados. Esses dados podem incluir: o que elas digitam, as imagens que compartilham, os áudios que gravam, as perguntas que fazem.

**A LGPD protege esses dados**, especialmente os de crianças e adolescentes, que merecem proteção reforçada pela lei brasileira.

Este documento explica, em linguagem simples, o que professores, pais e gestores escolares precisam saber antes de implementar qualquer atividade com IA.

---

## 📋 O que diz a LGPD sobre crianças?

O **Artigo 14 da LGPD** estabelece que:

- O tratamento de dados pessoais de **crianças (menores de 12 anos)** só pode ser feito com **consentimento específico dos pais ou responsáveis**
- O tratamento de dados de **adolescentes (12 a 17 anos)** deve observar o **melhor interesse** do menor
- Toda coleta de dados deve ser feita com **finalidade específica e transparente**
- Os dados coletados devem ser os **mínimos necessários** (princípio da minimização)

## ✅ Regras práticas para professores

### O que SEMPRE fazer:

| Situação | Ação Correta |
|---------|-------------|
| Usar ferramenta de IA com alunos | Verificar se a plataforma tem política de privacidade compatível com menores |
| Demonstrar uso de chatbot | Usar nome fictício e informações inventadas nos exemplos |
| Pedir para alunos interagirem com IA | Orientar que nunca digitem nome completo, escola ou endereço |
| Criar conta em plataforma educacional | Verificar se a escola tem convênio que cobre privacidade dos dados |
| Gravar aula com alunos usando IA | Obter autorização prévia por escrito dos responsáveis |

### O que NUNCA fazer:

- ❌ Pedir que alunos criem contas pessoais em plataformas de IA sem autorização dos pais
- ❌ Usar fotos reais de alunos em ferramentas de reconhecimento de imagem
- ❌ Deixar alunos compartilharem dados pessoais em chatbots
- ❌ Gravar ou armazenar interações de alunos menores com IA sem consentimento
- ❌ Compartilhar produções de alunos online sem autorização específica

---

## 🔍 Como avaliar se uma plataforma de IA é segura para menores?

Use estas perguntas como checklist:

```
□ A plataforma tem Política de Privacidade acessível em português?
□ Ela menciona especificamente o tratamento de dados de menores?
□ Existe modo educacional ou "classroom" para escolas?
□ Os dados são armazenados em servidores no Brasil ou com adequação à LGPD?
□ A plataforma permite uso sem criação de conta (modo visitante)?
□ Há possibilidade de excluir os dados após o uso?
□ A escola ou a rede municipal assinou algum contrato de proteção de dados com a plataforma?
```

## 📱 Plataformas avaliadas para uso no projeto IA para Todos

As seguintes ferramentas foram avaliadas para uso educacional com crianças e adolescentes brasileiros:

### ✅ Recomendadas para uso em sala (com supervisão)

| Ferramenta | Faixa Etária | Observação |
|-----------|-------------|------------|
| **Teachable Machine (Google)** | 6+ | Offline possível, sem conta, dados ficam locais |
| **Scratch + extensões de IA** | 6+ | Plataforma educacional consolidada, dados minimizados |
| **Quick, Draw! (Google)** | 6+ | Sem conta, sem dados pessoais, totalmente lúdico |
| **AI Experiments (Google Arts)** | 8+ | Sem conta necessária, dados não são armazenados |
| **ChatGPT Edu** | 13+ | Apenas para escolas com contrato educacional |
| **Gemini for Education** | 13+ | Apenas via Google Workspace for Education |

### ⚠️ Usar com atenção

| Ferramenta | Atenção Necessária |
|-----------|-------------------|
| ChatGPT (versão pública) | Não recomendado para menores de 13 anos — crie conta da escola |
| Plataformas de geração de imagem | Monitorar o que crianças geram e inserem |
| Assistentes de voz (Alexa, Google) | Dados de voz são coletados — verificar configurações |

### ❌ Não usar com menores de 13 anos

- Plataformas de IA sem política de privacidade clara
- Ferramentas que exigem dados biométricos (impressão digital, rosto)
- Plataformas que exigem cadastro com CPF ou dados financeiros

## 📄 Documentos que sua escola deve ter

Para implementar o projeto com segurança legal, recomendamos que a escola possua:

1. **Autorização de uso de imagem e dados digitais** — assinada pelos responsáveis no início do ano letivo
2. **Política de uso de tecnologia da escola** — aprovada pelo Conselho Escolar
3. **Mapeamento de dados** — registro de quais ferramentas digitais são usadas e quais dados coletam
4. **Plano de resposta a incidentes** — o que fazer em caso de vazamento ou uso indevido de dados

*Modelos desses documentos estão disponíveis na pasta [`recursos-professores/`](../recursos-professores/).*

## 👨‍👩‍👧 Direitos dos pais e responsáveis

De acordo com a LGPD, os responsáveis legais têm o direito de:

- **Saber** quais dados de seus filhos estão sendo coletados
- **Acessar** esses dados quando solicitado
- **Corrigir** dados incorretos
- **Eliminar** dados que não sejam mais necessários
- **Revogar** o consentimento dado anteriormente
- **Reclamar** à ANPD (Autoridade Nacional de Proteção de Dados) em caso de violação

---

## 🆘 O que fazer se houver um incidente?

Se um aluno compartilhar dados pessoais inadvertidamente, ou se houver suspeita de uso indevido de dados:

1. **Encerre imediatamente** a sessão ou interação em questão
2. **Documente** o ocorrido (o que foi compartilhado, com qual plataforma, em que horário)
3. **Notifique** a coordenação pedagógica e a direção escolar
4. **Informe** os pais ou responsáveis pelo aluno envolvido
5. **Entre em contato** com a plataforma para solicitar exclusão dos dados
6. **Registre** o incidente no livro de ocorrências da escola

Em casos mais graves (exposição de dados sensíveis, suspeita de abuso), acione a direção para contato com o DPO (Encarregado de Dados) da rede municipal de ensino.
