# 💾 Como Usar o Pendrive Bootável — Projeto IA para Todos (Multicortex)

> *Inteligência Artificial funcionando 100% offline, em qualquer computador, sem instalação*

---

## O que é o Pendrive Bootável do IA para Todos?

O **Pendrive Bootável** desenvolvido pela **Multicortex** é uma solução revolucionária para escolas públicas brasileiras: um pen drive USB que transforma **qualquer computador** em uma estação completa de IA educacional — **sem precisar de internet, sem instalação, sem configuração**.

Basta plugar o pendrive, ligar o computador, e em poucos minutos você tem acesso a todas as ferramentas e atividades do projeto IA para Todos.

**É a resposta para a pergunta: "Como faço IA educacional em uma escola sem internet boa?"**

---

## 🖥️ O que vem no pendrive?

O pendrive inclui:

### Ferramentas de IA (offline)
- **Modelos de linguagem locais** — chatbots de IA que funcionam sem internet
- **Reconhecimento de imagens** — classifique objetos usando a câmera
- **Síntese de voz e reconhecimento de fala** — IA que fala e entende português
- **Teachable Machine offline** — treine sua própria IA para reconhecer imagens ou sons
- **Gerador de texto simples** — para atividades de escrita criativa com IA

### Conteúdo educacional
- **Todas as atividades** deste repositório, em formato navegável offline
- **Vídeos explicativos** sobre IA para professores (sem necessidade de streaming)
- **Jogos e simulações** de aprendizado de máquina
- **Guias em PDF** para impressão

### Sistema operacional
- Linux educacional customizado (baseado em distribuição leve)
- Interface amigável em português
- Não modifica nem acessa os dados do computador anfitrião

## 🚀 Passo a passo para usar

### Antes de começar — o que você precisa:
- O pendrive do Projeto IA para Todos (obtido via escola ou Multicortex)
- Um computador (Windows, Mac ou Linux) — qualquer um com pelo menos 4 anos de uso funciona
- Cerca de 3-5 minutos para o primeiro boot

---

### Passo 1: Configurar o boot pelo USB

Esta é a parte que parece difícil, mas não é!

**No Windows:**
1. Desligue o computador completamente
2. Insira o pendrive em uma porta USB
3. Ligue o computador e **imediatamente** pressione a tecla de boot (veja tabela abaixo)
4. Na tela de seleção, escolha o pendrive USB

| Marca do Computador | Tecla de Boot |
|-------------------|--------------|
| Dell | F12 |
| HP | F9 ou ESC |
| Lenovo | F12 ou Enter |
| Acer | F12 |
| Asus | F8 |
| Samsung | F2 |
| Genérico | F11, F12 ou ESC |

> 💡 **Dica:** Se não souber a tecla, tente F12. É a mais comum. Pressione várias vezes rapidamente logo que o computador começar a ligar.

**No Mac:**
1. Desligue o Mac
2. Insira o pendrive
3. Ligue e segure a tecla **Option (⌥)** até aparecer a tela de seleção de disco
4. Escolha o pendrive (aparecerá como "EFI Boot" ou "IA para Todos")

---

### Passo 2: Aguardar o carregamento

Na primeira vez, o sistema leva entre 2-4 minutos para carregar. Nas próximas vezes, é mais rápido.

Você verá:
1. Tela de splash do **IA para Todos / Multicortex**
2. Barra de progresso de carregamento
3. Desktop com interface em português

---

### Passo 3: Navegar pelo conteúdo

Na área de trabalho, você verá ícones para:

```
📚 Atividades por Ano    → Atividades organizadas do 1º ao 9º ano
🤖 Ferramentas de IA     → Acesso direto às ferramentas offline
👩‍🏫 Recursos Professores  → Planos de aula, slides, rubricas
📖 Guias                 → Guias para professores, pais e alunos
🎮 Jogos de IA           → Atividades gamificadas de aprendizado
```

---

### Passo 4: Ao terminar

1. Feche todos os programas
2. Clique em **"Desligar"** no menu do sistema
3. Aguarde o computador desligar completamente
4. **Retire o pendrive somente após o desligamento completo**

> ⚠️ **Importante:** Nunca retire o pendrive enquanto o sistema estiver rodando. Isso pode corromper os dados.

## ❓ Problemas comuns e soluções

### "O computador não abre pelo pendrive, vai direto para o Windows"

**Solução:** A BIOS/UEFI pode ter o secure boot ativado ou a ordem de boot configurada para HD primeiro.

Peça ajuda ao responsável pelo laboratório de informática da escola, ou entre em contato com o suporte Multicortex com o modelo do computador.

### "A tela ficou preta ou travou no carregamento"

**Solução:** Desligue (botão físico, segure por 5 segundos), aguarde 30 segundos e tente novamente. Se persistir, anote o erro que aparece e entre em contato com o suporte.

### "O áudio não está funcionando"

**Solução:** Vá em Menu → Configurações → Som e selecione o dispositivo de saída correto. Alguns computadores antigos precisam de configuração manual.

### "As atividades não aparecem"

**Solução:** Aguarde o carregamento completo do sistema (pode levar até 5 minutos em computadores mais lentos). Se o ícone "Atividades" ainda não aparecer, reinicie o sistema pelo pendrive.

### "A câmera não funciona para as atividades de imagem"

**Solução:** A ferramenta de câmera funciona apenas em computadores com webcam integrada ou USB. Verifique se a câmera está conectada antes de iniciar o sistema.

## 🏫 Para gestores escolares: como implementar em escala?

### Para um laboratório de informática inteiro:

Não é necessário um pendrive por computador. Opções:

1. **Um pendrive rodando por vez** — demonstrações no projetor
2. **Kit escolar** (5-10 pendrives) — atividades em pequenos grupos
3. **Imagem de disco** — a Multicortex oferece solução para clonar o sistema em HDs locais das máquinas (consulte o suporte)

### Para escolas com internet eventual:

O pendrive funciona offline, mas quando há internet disponível, ele detecta automaticamente e baixa atualizações de conteúdo em segundo plano.

### Como obter mais pendrives:

Entre em contato com a **Multicortex** ou com o **LABRIOT (UTFPR)** para informações sobre distribuição para redes municipais de ensino.
