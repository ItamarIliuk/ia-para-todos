## 💡 Sobre o Projeto

O **IA para Todos** nasceu de um compromisso: nenhuma criança brasileira deve ficar de fora da revolução da Inteligência Artificial por falta de acesso a recursos de qualidade.

Este repositório reúne um currículo completo, progressivo e gratuito de **letramento em IA generativa** para o Ensino Fundamental — do 1º ao 9º ano — desenvolvido especialmente para a realidade das escolas públicas municipais do Brasil.

Todo o material é:
- ✅ **Gratuito** — sem custo algum para escolas, professores, alunos e famílias
- ✅ **Offline-first** — funciona no pendrive bootável do Projeto IA para Todos (Multicortex)
- ✅ **Alinhado à BNCC** — cada atividade conectada às competências nacionais
- ✅ **Ético e seguro** — pensado com cuidado para a proteção de crianças e adolescentes (LGPD)
- ✅ **Acolhedor** — linguagem clara para professores, pais e alunos

## 🚀 Como Começar

### Para Professores

1. **Leia primeiro:** [`docs/guia-professores.md`](docs/guia-professores.md)
2. **Escolha o ano** de seus alunos na pasta correspondente
3. **Abra a pasta `atividades/`** e escolha uma atividade
4. **Leia o arquivo `para-o-professor.md`** — está tudo explicado lá
5. **Imprima ou projete** a folha do aluno ou use no pendrive

### Para Usar no Pendrive Multicortex

Veja o guia completo: [`docs/como-usar-pendrive.md`](docs/como-usar-pendrive.md)

O pendrive bootável do Projeto IA para Todos já vem com todas as ferramentas de IA configuradas e prontas para funcionar **sem internet**, ideal para escolas com conectividade limitada.

### Para Pais e Responsáveis

Veja: [`docs/guia-pais.md`](docs/guia-pais.md)

## 🛡️ Compromisso com a Segurança das Crianças

Este projeto foi desenvolvido com atenção especial à **proteção de dados de menores** e à **LGPD (Lei Geral de Proteção de Dados)**:

- Nenhuma atividade coleta dados pessoais de crianças
- Todas as ferramentas indicadas possuem modo educacional seguro
- O uso de imagens, voz e dados pessoais é sempre discutido criticamente nas atividades
- Existe uma seção específica sobre segurança digital em cada faixa etária

Leia mais: [`docs/lgpd-criancas.md`](docs/lgpd-criancas.md)
