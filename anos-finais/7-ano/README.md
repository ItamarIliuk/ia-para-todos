# 🔐 7º Ano — "Privacidade, Dados e Você"

**Faixa etária:** 12-13 anos | **Ciclo:** Anos Finais

---

## 💡 Visão Geral do Ano

O 7º ano é dedicado ao tema mais urgente e pessoal para adolescentes de 12-13 anos: **privacidade digital**. Nesta faixa etária, muitos já têm celular, redes sociais, jogos online — e não percebem a extensão dos dados que estão gerando e compartilhando.

A pergunta central do ano: *"O que você vale em dados — e quem está lucrando com isso?"*

---

## 🎯 Objetivos de Aprendizagem

- [ ] Compreender o que são dados pessoais e dados sensíveis
- [ ] Entender como as plataformas coletam e usam dados para treinar IA
- [ ] Conhecer seus direitos sob a LGPD
- [ ] Desenvolver práticas de higiene digital
- [ ] Refletir sobre o valor econômico dos dados pessoais

## 👩‍🏫 Orientações para o Professor

### O dado que parece inofensivo

Alunos frequentemente pensam: *"Que mal faz dar meu nome?"* Use estes exemplos para mostrar como dados aparentemente inofensivos se tornam poderosos quando combinados:

```
Nome + Escola + Bairro + Horário de saída = Perfil de localização de uma criança menor
```

```
Curtidas + Tempo de tela + Horário de acesso = Perfil psicológico mais preciso que o de um terapeuta
```

```
CEP + Histórico de compras + Dados de saúde = Decisão de crédito ou seguro
```

### Atividade destaque: Ativ. 01 — "Quanto Você Vale em Dados?"

Em 2018, foi revelado que cada usuário do Facebook valia cerca de US$7/ano em receita de anúncios — baseada em análise de dados comportamentais. Em países mais ricos, esse valor pode chegar a US$50+.

Peça que os alunos calculem: *"Se você usa as redes sociais por 5 anos desde os 12 anos... quanto de dados você vai ter dado de graça?"*
